How it works

  1. A password-derived key encrypts the message with authenticated AES-256-GCM.
  2. The encrypted bytes are embedded in the least significant bits of RGB pixel channels.
  3. The decoder reads the stored payload length, extracts the bytes, then authenticates and decrypts them.

Use PNG files. Re-saving through JPEG or image optimization can destroy hidden data. This is an educational project, not a substitute for a reviewed secure communication system.
